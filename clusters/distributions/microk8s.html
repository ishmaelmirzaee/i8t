MicroK8s

They say, it’s a production-ready enterprise-grade solutions. However, think about the following we need to add about 100 servers to our cluster, do it one at a time. Do not be in hurry.
— MicroK8s
Ubuntu support classic mode
sudo ln -s /path/to/snap /snap
Install microk8s using snapp command
sudo snap install microk8s --class
Wait to our cluster be ready
microk8s status --wait-ready
Use add-ons manager to install DNS and Storage service
microk8s enable dns storage
Use integrated kubectl to get list of nodes
microk8s kubectl get nodes
