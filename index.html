What is Kubernetes (K8s)?

It is an orchestration tool. In many books, you see they say it is a container orchestration tool. However, since the introduction of K8s in 20xx; the community worked to enhance K8s capabilities. As of writing this piece, we can use K8s to manage Virtual Machines (VMs) as well as Containers. Thus, it is not only a Container orchestrator, but also, a VM orchestrator as well.

What does orchestration mean?

It means we can use a tool to manage the lifecycle of our application. Yet, the tool runs our application, it also checks for errors, or failures in out application and as of error in our application, it can bring up a new replacement to our application. ??Also, it automates the future deployment of our application.

How does K8s work?

The latest version of K8s uses several plugin interfaces which allows third-parties softwares connect to the K8s; for example, Container Runtime Interfaces allows wide variety of container runtime (e.g., Docker, cri-o) connect to kubelet, or Container Storage Interface (CSI) enables companies to connect their solutions to K8s (e.g., OpenEBS).

Distributions

Several companies introduced their own implementation of K8s, including Google, Red Hat, Canonical, OpenSuse. Each distribution comes with a handful of features, however they provide the same intention (orchestrating containers).
