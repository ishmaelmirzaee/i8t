Normal Pod

Generally, Pod is managed by Kubernetes API Server.

Static Pod

A Static Pod is a Pod that is managed by the Kubelet on each worker node.

Static Pod creation workflow

A typical manifest directory is
ls /etc/kubernetes/manifests/
How does it work

  1. Create a Pod manifest where the kubelet monitors

  2. As soon as kubelet detects the new manifest instructs the container runtime to run the Pod

  3. If the Pod fails, kubelet restarts it

  4. Periodically kubelet checks for changes

Static Pods are the part of the process to run several components by Kubeadm

  • Kubernetes API Server

  • Kubernetes Controller Manager

  • Kubernetes Scheduler

  • On the of using local etcd etcd

Static Pods are crucial since the control plane can start without first requiring a functioning Kubernetes API Server
